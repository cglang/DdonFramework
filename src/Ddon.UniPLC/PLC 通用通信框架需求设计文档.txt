# PLC 通用通信框架需求设计文档（初稿）

## 1. 项目目标

设计并实现一个可扩展的 PLC 通信框架，统一接入不同品牌 PLC（如西门子 Siemens、三菱 Mitsubishi、欧姆龙 Omron 等），通过统一 API 完成：

* 建立连接 / 断开连接
* 检测连接状态
* 读取 PLC 数据
* 写入 PLC 数据
* 批量读写
* DB 块 / 寄存器映射
* 内存模拟器（Mock PLC）
* 插件式扩展新品牌 PLC
* 类似 EFCore 的注册方式

目标风格：

```csharp
services.AddPlc(options =>
{
    options.UseSiemens(x =>
    {
        x.Ip = "192.168.1.10";
        x.Port = 102;
        x.Rack = 0;
        x.Slot = 1;
    });

    options.UseMitsubishi(...);
});
```

---

# 2. 核心设计原则

## 2.1 抽象统一（Abstraction）

屏蔽品牌差异：

* 西门子：DB 块（DB Block）
* 三菱：D/M/X/Y 寄存器
* 欧姆龙：CIO/DM/W/HR

统一抽象为：

```csharp
PlcAddress
```

---

## 2.2 可扩展（Extensible）

新增 PLC 品牌时：

只需实现：

```csharp
IPlcClient
IPlcAddressParser
IPlcSerializer
```

注册：

```csharp
UseBrandX()
```

---

## 2.3 高性能（High Performance）

支持：

* 长连接池（Connection Pool）
* 异步 IO（async/await）
* 批量读取（Batch Read）
* 地址合并读取（Block Merge Read）
* 零拷贝 Span<byte>

---

## 2.4 高可靠（Reliable）

支持：

* 自动重连（Reconnect）
* 心跳检测（Heartbeat）
* 超时控制（Timeout）
* 重试策略（Retry Policy）
* 日志追踪（Logging）
* 熔断（Circuit Breaker）

---

# 4. 核心接口设计

---

## 4.1 IPlcClient

```csharp
public interface IPlcClient : IAsyncDisposable
{
    string Name { get; }

    bool IsConnected { get; }

    Task ConnectAsync();

    Task DisconnectAsync();

    Task<bool> PingAsync();

    Task<PlcReadResult<byte[]>> ReadBytesAsync(string address, int length);

    Task<PlcWriteResult> WriteBytesAsync(string address, byte[] data);

    Task<T> ReadAsync<T>(string address);

    Task WriteAsync<T>(string address, T value);

    Task<IReadOnlyList<PlcValueResult>> BatchReadAsync(params string[] addresses);
}
```

---

## 4.2 IPlcProvider

```csharp
public interface IPlcProvider
{
    IPlcClient GetClient(string name);

    T GetClient<T>() where T : IPlcClient;
}
```

```csharp
public interface IPlcClientFactory
```

# 6. 地址统一模型（关键）

## 为什么必须做？

不同 PLC 地址差异极大。

例如：

| 品牌         | 地址         |
| ---------- | ---------- |
| Siemens    | DB1.DBX0.0 |
| Mitsubishi | D100       |
| Omron      | DM100      |

必须统一解析。

---

## Address Model

```csharp
public class PlcAddress
{
    string Area;      // DB / D / M / CIO
    int BlockNumber;
    int Offset;
    int Bit;
    DataType Type;
}
```

# 8. 高级对象映射（建议必须做）

类似 ORM。

```csharp
public class MotorState
{
    [PlcAddress("DB1.DBX0.0")]
    public bool Run { get; set; }

    [PlcAddress("DB1.DBD4")]
    public float Speed { get; set; }
}
```

读取：

```csharp
var motor = await client.ReadModelAsync<MotorState>();
```

写入：

```csharp
await client.WriteModelAsync(motor);
```

这个功能价值极高。

# 9. Siemens 专项支持

你提到 DB 块长度，这里建议做成：

```csharp
options.UseSiemens(x =>
{
    x.DbBlock(1, 256);
    x.DbBlock(2, 128);
});
```

框架自动缓存 DB Metadata。

支持：

* DB Read
* DB Write
* M 区
* I/Q 区
* Timer
* Counter

# 19. 二级思考（关键建议）

当前思路是对的，但有一个潜在问题，真正难点是：

## 地址模型统一

和

## 数据映射统一

以及

## 通信稳定性

如果这三个没做好，框架会很快失控。

所以建议优先级：

```text
第一阶段：
IPlcClient
Provider
SiemensClient
MemoryClient

第二阶段：
Address Parser
Type Serializer
Model Mapping

第三阶段：
Reconnect
Subscribe
Batch Read
Plugin

第四阶段：
Mitsubishi / Omron / Modbus
```
