# Ddon.OpenProtocol 重构方案

## 架构概述

```
┌─────────────────────────────────────────────────────────┐
│                    Application                          │
├─────────────────────────────────────────────────────────┤
│  IOpenProtocolManager  →  OpenProtocolManager           │
│    └─ IOpenProtocolEndpoint  →  OpenProtocolEndpoint    │
│          ├─ ISocketWorker (Ddon.Socket)  ← TCP 传输    │
│          ├─ IOpenProtocolProtocol       ← MID 编解码    │
│          ├─ RequestResponseMatcher      ← 请求响应匹配   │
│          ├─ OpenProtocolEventBus        ← 推送事件分发   │
│          ├─ IOpenProtocolPipeline       ← 中间件链      │
│          └─ IReconnectStrategy (Ddon.Socket)  ← 重连    │
└─────────────────────────────────────────────────────────┘
```

## 核心设计

### 1. 复用 Ddon.Socket

| 复用组件 | 用途 |
|----------|------|
| `ISocketWorker` | TCP 连接、收发字节、断开事件 |
| `ISocketFactory` | 创建 ISocketWorker 实例 |
| `IReconnectStrategy` | 断线重连策略 |
| `SocketClientOptions` | TCP 传输配置（Host/Port/Timeout） |

### 2. 终止符可配置 (解决旧问题 1)

```csharp
public enum MessageTerminator { None, Nul, CrLf, Custom }

public class OpenProtocolEndpointOptions
{
    public MessageTerminator Terminator { get; set; } = MessageTerminator.Nul;
    public byte[] CustomTerminator { get; set; } = [];
}
```

`IOpenProtocolProtocol.Serialize(Mid)` 根据配置追加对应终止符。

### 3. Mid0004 错误处理 (解决旧问题 2)

`RequestResponseMatcher` 检测 Mid0004 → 提取 `FailedCommandMid` → 反查 `ResponseMap` → 找到待处理项 → 抛出 `OpenProtocolException`：

```csharp
try {
    var result = await endpoint.SendAsync<Mid0005>(new Mid0018());
}
catch (OpenProtocolException ex) when (ex.FailedMid == 0018) {
    Console.WriteLine($"命令失败: {ex.ErrorCode}");
}
```

### 4. 订阅可等待 (解决旧问题 3)

```csharp
// 订阅 + 等待首个结果
var first = await endpoint.SubscribeAsync<Mid0061>(new Mid0060());

// 后续结果通过事件订阅接收
endpoint.Subscribe<Mid0061>(result => OnTightening(result));
```

`SubscribeAsync` = 发送订阅请求 + 记录到重发列表 + 创建一次性等待项。首个响应完成 Task，后续进入 EventBus。

### 5. 类型驱动 MID 注册 (解决旧问题 5)

自定义 MID 必须定义 `public const int MID` 常量，API 自动读取：

```csharp
public class MyMid0999 : Mid
{
    public const int MID = 999;
    // ...
}

// 注册：从 typeof 读取 MID=999
endpoint.RegisterCustomMid<MyMid0999>();

// 映射：从类型读两端 MID
endpoint.MapResponse<MyMid0999, Mid0005>();
```

无需硬编码数字。

## 数据流

```
Send:  SendAsync<Mid0002>(new Mid0001())
         → _matcher.Enqueue(Mid=1, timeout)
         → _protocol.Serialize(mid)        [按 Terminator 追加 NUL/CrLf/...]
         → _worker.SendAsync(bytes)

Recv:  _worker.DataReceived
         → ReceiveLoopAsync (Channel-based)
         → PacketFramer 拆帧
         → _protocol.Deserialize(packet)   [含 SafeParse revision 降级]
         → _matcher.TryMatch(mid)
             ├─ matched (含 Mid0004) → 完成 Task (或抛异常)
             └─ unmatched → Pipeline → EventBus
```

## 关键 API

```csharp
public interface IOpenProtocolEndpoint
{
    string Name { get; }
    bool IsConnected { get; }

    Task StartAsync(CancellationToken ct = default);
    Task StopAsync(CancellationToken ct = default);

    Task<TResponse> SendAsync<TResponse>(Mid request, CancellationToken ct = default)
        where TResponse : Mid;

    Task<TResponse> SubscribeAsync<TResponse>(Mid request, CancellationToken ct = default)
        where TResponse : Mid;

    Task RegisterSubscriptionAsync(Mid request, CancellationToken ct = default);

    IDisposable Subscribe<TMid>(Func<TMid, Task> handler) where TMid : Mid;
    IDisposable Subscribe<TMid>(Action<TMid> handler) where TMid : Mid;
    IDisposable SubscribeAll(Func<Mid, Task> handler);
}
```
