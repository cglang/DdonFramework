## 1. 设计目标

### 功能目标

* 支持多个 COM 口同时工作
* 每个 COM 独立配置、独立生命周期
* 每个 COM 拥有独立 Pipeline
* 每个 COM 拥有独立 Handler 集合
* 每个 COM 可独立配置 Protocol
* 每个 COM 可独立配置重连策略
* 支持独立实例创建
* 支持 Microsoft Dependency Injection
* 支持 Generic Host
* 支持可选 HostedService
* 支持自动重连
* 支持 Pipeline 扩展

# 2. 总体架构

```
Application
        │
        ▼
ISerialManager
        │
        ├──────────────┬──────────────┐
        ▼              ▼              ▼
 Endpoint(COM1)   Endpoint(COM2)  Endpoint(COM3)
        │              │              │
        ▼              ▼              ▼
SerialWorker   SerialWorker   SerialWorker
        │              │              │
        ▼              ▼              ▼
   Pipeline       Pipeline       Pipeline
        │              │              │
        ▼              ▼              ▼
  Dispatcher     Dispatcher     Dispatcher
        │              │              │
        ▼              ▼              ▼
 Handler[]      Handler[]      Handler[]
```

Manager 不参与数据处理，仅负责 Endpoint 的创建、启动、停止和管理。

# 4. 核心对象

## ISerialManager

职责：

* 创建 Endpoint
* 删除 Endpoint
* 获取 Endpoint
* 启动全部 Endpoint
* 停止全部 Endpoint

内部维护：

```
ConcurrentDictionary<string, ISerialEndpoint>
```

Manager 不负责通信。

---

## ISerialEndpoint

一个 Endpoint 对应一个 COM。

例如：

```
COM3

↓

SerialEndpoint

↓

SerialWorker

↓

ReceiveLoop
```

Endpoint 内部拥有：

* SerialWorker
* Pipeline
* Dispatcher
* Handler 集合
* Protocol
* ReconnectStrategy

每个 Endpoint 完全独立。

---

## SerialWorker

职责：

```
Open

Close

Read

Write

Reconnect
```

只负责串口 IO，不处理业务。

---

# 5. 数据接收流程

```
COM3

↓

Read()

↓

Protocol

↓

Pipeline

↓

Dispatcher

↓

Handler1

↓

Handler2

↓

Handler3
```

所有流程仅发生在当前 Endpoint 内部。

---

# 6. Dispatcher

每个 Endpoint 拥有自己的 Dispatcher。

```
COM1
    Dispatcher
        ↓
    PlcHandler
    LoggerHandler

COM2
    Dispatcher
        ↓
    ScannerHandler

COM3
    Dispatcher
        ↓
    WeightHandler
```

Dispatcher 不共享。

---

# 7. Pipeline

每个 Endpoint 拥有独立 Pipeline。

例如：

```
Receive

↓

LoggingMiddleware

↓

StatisticsMiddleware

↓

FrameParser

↓

CRCValidator

↓

Dispatcher
```

不同 COM 可以拥有完全不同的 Pipeline。

---

# 8. Handler

Handler 只属于当前 Endpoint。

例如：

```
COM1

↓

LoggerHandler

↓

PlcHandler
```

```
COM2

↓

ScannerHandler
```

```
COM3

↓

WeightHandler
```

一个 Handler 不会收到其他 COM 的消息。

---

# 9. Protocol

Protocol 负责：

* 编码
* 解码
* 帧解析
* CRC 校验（可选）

例如：

```
COM1

↓

ModbusProtocol
```

```
COM2

↓

ScannerProtocol
```

```
COM3

↓

WeightProtocol
```

Protocol 同样属于 Endpoint。


# 11. HostedService

HostedService 不负责任何业务。

启动：

```
Manager

↓

OpenAll()

↓

Endpoint.Start()
```

停止：

```
Manager

↓

CloseAll()

↓

Endpoint.Stop()
```

# 12. Builder

Builder 采用两级结构。

第一层负责管理所有 Endpoint：

```csharp
services.AddSerial(builder =>
{
    builder.AddEndpoint("PLC", endpoint =>
    {
    });

    builder.AddEndpoint("Scanner", endpoint =>
    {
    });

    builder.AddEndpoint("Weight", endpoint =>
    {
    });
});
```

第二层负责配置当前 Endpoint：

```csharp
builder.AddEndpoint("PLC", endpoint =>
{
    endpoint.Configure(options =>
    {
        options.PortName = "COM1";
        options.BaudRate = 115200;
    });

    endpoint.UseProtocol<ModbusProtocol>();

    endpoint.UseReconnect<DefaultReconnectStrategy>();

    endpoint.UseBackgroundService();

    endpoint.UsePipeline(pipeline =>
    {
        pipeline.Use<LoggingMiddleware>();
        pipeline.Use<CrcMiddleware>();
    });

    endpoint.AddHandler<LoggerHandler>();

    endpoint.AddHandler<PlcHandler>();
});
```

每个 Endpoint 的配置互不影响。

# 15. 推荐使用方式

普通模式：

```csharp
var manager = new SerialManager();

manager.AddEndpoint(endpoint =>
{
    endpoint.Configure(...);

    endpoint.AddHandler<PlcHandler>();
});

manager.StartAll();
```

DI 模式：

```csharp
builder.Services.AddSerial(builder =>
{
    builder.AddEndpoint("PLC", endpoint =>
    {
        endpoint.Configure(options =>
        {
            options.PortName = "COM1";
        });

        endpoint.UseProtocol<ModbusProtocol>();

        endpoint.UsePipeline(pipeline =>
        {
            pipeline.Use<LoggingMiddleware>();
        });

        endpoint.AddHandler<LoggerHandler>();
        endpoint.AddHandler<PlcHandler>();
    });

    builder.AddEndpoint("Scanner", endpoint =>
    {
        endpoint.Configure(options =>
        {
            options.PortName = "COM2";
        });

        endpoint.UseProtocol<ScannerProtocol>();

        endpoint.AddHandler<ScannerHandler>();
    });
});
```
