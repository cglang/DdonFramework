# 外部程序接入规范

## 概述

定义非 Lua 的 .NET 程序（自定义 Handler、插件、第三方服务）接入平台的三种方式，以及新增设备类型接入 OPC UA 的规范。

## 方式一：DI 直接注入（进程内，推荐）

适用于与 VitrinRuntime 同一进程的程序。

### 点位读写

```csharp
public class MyService
{
    private readonly IPlcHub _hub;

    public MyService(IPlcHub hub)
    {
        _hub = hub;
    }

    public void DemoAccess()
    {
        // 列出所有 PLC
        foreach (var name in _hub.Names)
        {
            var session = _hub.For(name);

            // 读取点位（从内存镜像，零阻塞）
            int value = session.Get<int>("D001");

            // 写入点位（直接写 PLC，异步）
            await session.SetAsync("D001", 200);

            // 订阅点位变化
            session.Subscribe<int>("D001", newVal =>
            {
                Console.WriteLine($"D001 变化为: {newVal}");
            });

            // 列出该 PLC 下所有 Tag
            foreach (var tag in session.Tags)
            {
                Console.WriteLine($"{tag.Name} @ {tag.Address} ({tag.Type})");
            }
        }
    }
}
```

### 事件订阅

```csharp
public class MyEventHandler
{
    public MyEventHandler()
    {
        // 订阅通用事件
        GeneralEventBus.Default.Subscribe((TagValueChangedEvent evt) =>
        {
            Console.WriteLine($"点位 {evt.TagName} 变化: {evt.OldValue} → {evt.NewValue}");
        });
    }
}
```

### 访问 OPC UA 节点（进程内）

```csharp
public class UaAccessService
{
    private readonly IVitrinUaServer _uaServer;

    public UaAccessService(IVitrinUaServer uaServer)
    {
        _uaServer = uaServer;
    }

    public void DirectNodeAccess()
    {
        // 直接操作 UA 节点（不走网络）
        var node = _uaServer.NodeManager.FindNode("PLC.PLC1.D001");
        if (node is BaseVariableState varNode)
        {
            var currentValue = varNode.Value;
            varNode.Value = 200; // 只改内存
            _uaServer.NodeManager.ApplyChanges(); // 通知订阅者
        }
    }
}
```

## 方式二：Bridge API（跨进程/远程）

适用于外部独立进程（Python、Node.js 或其他 .NET 进程）。

### HTTP 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `POST /api/bridge/invoke` | 通用调用 | 调用任意 BridgeMethod |
| `POST /api/bridge/event` | 发布事件 | 向平台发布事件 |

### 示例：Python 客户端

```python
import requests
import json

BASE_URL = "http://localhost:5000"

def bridge_invoke(method, payload=None):
    req = {
        "id": str(uuid.uuid4()),
        "method": method,
        "payload": payload
    }
    resp = requests.post(f"{BASE_URL}/api/bridge/invoke", json=req)
    data = resp.json()
    if not data["success"]:
        raise Exception(data["error"])
    return data["data"]

# 读取点位
result = bridge_invoke("PlcHub_ReadTag", {
    "plcName": "PLC1",
    "tagName": "D001"
})
print(f"D001 = {result}")

# 写入点位
bridge_invoke("PlcHub_WriteTag", {
    "plcName": "PLC1",
    "tagName": "D001",
    "value": 150
})
```

## 方式三：OPC UA 标准客户端

适用于 SCADA、MES、ERP 等支持 OPC UA 的第三方系统。

### 连接信息

| 参数 | 值 |
|------|-----|
| Endpoint URL | `opc.tcp://<host>:4840` |
| Security | 支持 None / Basic128Rsa15 / Basic256 |
| Authentication | Anonymous（默认）/ Username |

### 客户端示例（C#）

```csharp
using Opc.Ua;
using Opc.Ua.Client;

var config = new ApplicationConfiguration
{
    ApplicationName = "MyExternalApp",
    ApplicationType = ApplicationType.Client
};

var app = new ApplicationInstance(config);
await app.CheckApplicationInstanceCertificate(false, 0);

var endpoint = CoreClientUtils.SelectEndpoint("opc.tcp://localhost:4840", false);
var session = await Session.Create(config, endpoint, false, "MySession", 60000);

// 读取节点
var nodeId = new NodeId("PLC.PLC1.D001", 2);
var value = await session.ReadValueAsync(nodeId);

// 写入节点
var writeValue = new WriteValue
{
    NodeId = nodeId,
    AttributeId = Attributes.Value,
    Value = new DataValue(new Variant(200))
};
await session.WriteAsync(new[] { writeValue });

// 订阅变化
var subscription = new Subscription(session.DefaultSubscription) { PublishingInterval = 500 };
var item = new MonitoredItem
{
    StartNodeId = nodeId,
    AttributeId = Attributes.Value,
    MonitoringMode = MonitoringMode.Reporting,
    SamplingInterval = 500
};
item.Notification += (_, e) =>
{
    var val = e.Message.GetValue<DataValue>();
    Console.WriteLine($"值变化: {val.Value}");
};
subscription.AddItem(item);
session.AddSubscription(subscription);
subscription.Create();
```

## 新增设备类型接入规范

### 步骤

新增一个设备类型（如扫码枪、TCP 设备）到整个平台需完成以下步骤：

```
第 1 步：实现设备管理接口
├── IScannerManager / ITcpDeviceManager
├── 增删查改 API
├── 数据变更通知（通过 GeneralEventBus 或自定义事件发布）
└── DI 注册

第 2 步：实现 INodeProvider
├── 继承 INodeProvider
├── RootName = "BarcodeScanner" / "TCPDevice"
├── CreateNodes: 遍历已有设备创建节点树
├── AddChildNode: 运行时新增设备
├── RemoveChildNode: 运行时移除设备
└── DI 注册：services.AddSingleton<INodeProvider, ScannerNodeProvider>()

第 3 步（可选）：管理界面
├── Bridge Service（暴露设备管理操作）
├── Vue 管理页面
└── 主页面菜单卡片
```

### 约定

| 元素 | 约定 |
|------|------|
| 数据变更事件 | 通过 `GeneralEventBus.Default.Publish<T>()` 发布，Lua 脚本和 OPC UA 订阅者均可接收 |
| 设备状态 | 每个设备必须提供连接状态 Variable（Boolean），命名约定 `Connected` |
| 控制命令 | 执行命令暴露为 OPC UA Method，命名约定动词开头（如 `StartScan`、`Reset`） |
| 错误上报 | 错误信息通过 `GeneralEventBus` 发布 `DeviceErrorEvent` |
| 地址空间位置 | 一级子节点在 ObjectsFolder 下，与 "PLC"、"BarcodeScanner" 同级 |

## 完整的 API 索引

```
// ── 点位操作 ──
IPlcHub
  ├── Names                     → 列出所有 PLC
  ├── For(name)                 → 获取指定 PLC 的 Session
  └── AddPlcAsync / RemovePlcAsync

IPlcSession
  ├── Tags                      → 列出所有 Tag
  ├── Get<T>(tagName)           → 读取值
  ├── SetAsync<T>(tagName, val) → 写入值
  ├── Subscribe<T>(tagName, fn) → 订阅变化
  ├── AddTag(tag)               → 添加 Tag
  └── RemoveTag(tagName)        → 移除 Tag

// ── 事件系统 ──
GeneralEventBus.Default
  ├── Subscribe<T>(handler)     → 订阅事件
  ├── Subscribe<T>(asyncHandler)→ 订阅事件（异步）
  ├── Publish<T>(evt)           → 发布事件（同步）
  └── PublishAsync<T>(evt)      → 发布事件（等待完成）

// ── OPC UA 节点操作（进程内） ──
IVitrinUaServer
  ├── IsRunning                 → 运行状态
  ├── NodeManager               → 获取节点管理器
  ├── Start/Stop/StatusChanged

INodeManager
  ├── FindNode(path)            → 查找节点
  ├── CreateVariable(...)       → 创建变量节点
  ├── CreateMethod(...)         → 创建方法节点
  ├── CreateFolder(...)         → 创建目录节点
  ├── RemoveNode(path)          → 移除节点
  └── ApplyChanges()            → 提交变更

// ── Lua 脚本 ──
LuaEventBridgeService
  ├── SubscribeGroup(name)      → 订阅组的约定事件
  └── UnsubscribeGroup(name)    → 取消订阅

LuaPlatformApi (在 Lua 中为 Platform.*)
  ├── readTag(fullName)         → 读点位
  ├── writeTag(fullName, val)   → 写点位
  ├── httpGet(url, headers?)    → HTTP GET
  └── httpPost(url, body, hdrs?)→ HTTP POST
```
