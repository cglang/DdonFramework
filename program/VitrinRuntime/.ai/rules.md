# AI Agent Rules

## 高优先级约束规范

### 1. 自动更新项目上下文

每当完成任务并产生需要记录的信息时自动更新`.ai`目录下的文档。

### 2. 禁止全项目扫描

不要主动扫描整个项目。如果无法找到目标文件或相关代码，向用户询问具体位置。

### 3. 文件过滤规则

忽略以下文件 `*.zh.md`，除非用户明确要求查看。

### 4. 思考语言

内部分析和推理优先使用中文其次使用英文。

### 5. 模糊需求处理

当用户描述过于宽泛时：指出缺失信息、要求补充约束条件、不自行假设需求。

### 6. 不要写自定义CSS

主要使用Element UI自带的布局和样式，除非Element UI提供的无法满足需求，否则不要写CSS。


### 7. 前端页面不要使用URL传参

统一使用共享状态 store 进行页面数据的传递
