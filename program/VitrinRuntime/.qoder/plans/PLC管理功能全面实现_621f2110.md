# PLC 管理功能实现方案

## 数据结构设计

所有 PLC 配置、DB 分组和点位定义存储在内存中（`ConcurrentDictionary` 模拟持久化），后续可按需改用 JSON/数据库。

### 核心模型

```
PlcConfig { Name, Ip, Port(默认102), Rack(0), Slot(1), CreatedAt, IsConnected }
DbGroup { Id(Guid), PlcName, Name, DbNumber(int) }
TagConfig { Id(Guid), GroupId, Name, Address(如DB1.DBD0), DataType(PlcDataType) }
```

## 第一阶段：后端 C# 实现

### 文件 1: `Services/PlcConfigStore.cs`
- 内存存储 `PlcConfig`、`DbGroup`、`TagConfig`
- 提供 CRUD 方法

### 文件 2: `Services/PlcManagerService.cs`
`[BridgeService(Name = "PlcManager")]` 提供：
- `ListPlcs()` → `PlcConfig[]`
- `AddPlc(name, ip, port, rack, slot)` → 动态创建 SiemensClient 并添加到 IPlcHub
- `RemovePlc(name)` → 从 IPlcHub 移除并停止
- `ConnectPlc(name)` / `DisconnectPlc(name)` → 连接/断开
- `GetPlcStatus(name)` → 连接状态 + 镜像版本 + 更新时间

### 文件 3: `Services/PlcDataService.cs`
`[BridgeService(Name = "PlcData")]` 提供：
- `ListDbGroups(plcName)` → `DbGroup[]`
- `CreateDbGroup(plcName, groupName, dbNumber)` → 创建分组
- `DeleteDbGroup(groupId)` / `RenameDbGroup(groupId, newName)`
- `ListTags(groupId)` → `TagConfig[]`，同时从 Mirror 读取当前值
- `AddTag(groupId, tagName, address, dataType)` → 添加到分组 + 注册到 IPlcSession
- `RemoveTag(tagId)` → 从分组移除 + 从 IPlcSession 移除
- `ReadTag(tagId)` → 从 Mirror 读取当前值
- `WriteTag(tagId, value)` → 调用 IPlcSession.SetAsync() 写入 PLC

### 文件 4: `VitrinRuntime.Desktop.csproj` 修改
- 添加 `ProjectReference` 到 `Ddon.VitrinPLC`
- 或添加 NuGet 引用（取决于项目构建方式）

### 文件 5: `App.axaml.cs` 修改
- 注册 `IPlcHub`（AddVitrinPlc，初始空配置，后续动态添加）
- 注册 `PlcConfigStore`（Singleton）
- 注册 `PlcManagerService`、`PlcDataService`（Singleton）

## 第二阶段：前端 Vue 实现

### 文件 6: `src/bridge.ts` 扩展
- 添加 `PlcManager` 和 `PlcData` 的强类型方法

### 文件 7: `src/views/PlcListView.vue`
- 网格卡片布局展示 PLC 列表（使用 Element Plus Card）
- 每个卡片显示：名称、IP、状态指示灯、连接/断开按钮
- 底部"添加 PLC"按钮 → 弹窗（IP、端口、机架、槽位）
- 点击卡片进入详情页

### 文件 8: `src/views/PlcDetailView.vue`
- 顶部：PLC 信息栏（名称、IP、状态）
- 中间：DB 分组列表（可编辑名称的分组标签页）
- 左侧：分组列表（可重命名、删除），"新建分组"按钮
- 右侧：选中分组的 Tag 表格

### 文件 9: `src/components/TagTable.vue`
- Element Plus Table 展示标签
- 列：名称、地址、类型、当前值、操作
- 值可原地编辑（输入框/开关/数字输入 根据类型自适应）
- "添加点位"按钮 → 弹窗（名称、地址、数据类型选择）
- 定时轮询刷新（或基于订阅推送）

### 文件 10: `src/router/index.ts` 修改
- 添加路由：`/plc/list` → PlcListView
- 添加路由：`/plc/detail/:name` → PlcDetailView
- 添加路由：`/main` 中增加导航入口

## 路由结构

```
/main          → 主页面（可添加 PLC 管理入口导航）
/plc/list      → PLC 列表（网格卡片）
/plc/detail/:name → PLC 详情（DB分组 + 点位管理）
```

## 第三方依赖

无需额外 NuGet 包，`S7netplus` 已在 `Ddon.VitrinPLC.csproj` 中引用。

## 关键设计决策

1. **动态 PLC 注册**：使用 `IPlcHub.AddPlcAsync()` 运行时添加，而非启动时静态配置
2. **分组与 Tag 分离**：`DbGroup` 是前端逻辑分组，`TagDefinition` 是框架层面的点位定义
3. **值刷新机制**：利用 VitrinPLC 的 SyncEngine 自动扫描（200ms），前端通过 `session.Tags` 或定时 `ReadTag` 获取最新值
4. **数据持久化**：先使用内存存储，后续可按需改为 JSON 文件存储
