### 踩坑记录（重要）
1. **naive-ui 的 `n-table`/`n-table-column` 不支持 data/复选框/row-key** —— 需要列配置、行选择时必须用 `n-data-table`（columns 数组 + render 函数）。`n-table-column` 不是可独立使用的组件，之前用它 + slot 导致运行时 `Cannot destructure property 'row' of 'undefined'`。
2. **vue-tsc 3.3.7 对泛型组件（`generic="T"`）模板插槽类型推断有 bug** —— 插槽解构参数被推断为 `{}`，`#stock="{ row }: any"` 标注也不生效。解决：TableColumn 支持 `render?: (row, column) => VNodeChild` 函数优先于插槽，TS 项目里用 render 更稳。
3. **编辑模板时注意标签配对** —— 手动 Edit 改动后多留了一个 `</n-card>` 导致 vite 报 "Invalid end tag"（HTTP 500）。

## 上下布局 + 内容区滚动（App.vue 重构）

App.vue 改为手写 flex 上下布局（不再用 n-layout）：
- `.app-shell`（height 100%, flex column, overflow hidden）+ `.app-content`（flex: 1; min-height: 0; overflow-y: auto）
- main.css 加 `html, body, #app { height: 100%; overflow: hidden }`
- WorkbenchView 的 `min-height: 100vh` → `min-height: 100%`

### 踩坑（重要）
**n-config-provider 会渲染一个包裹 div（.n-config-provider），默认高度 auto**，会打断 html→#app→.app-shell 的百分比高度链，导致 .app-shell 的 height:100% 失效（被内容撑高）。必须在全局 CSS 补 `.n-config-provider { height: 100% }`。

naive-ui 的 n-layout（position absolute + scroll-container）默认不做"内容超高内部滚动"（scroll-container 只有 overflow-x: hidden，外层 overflow: hidden 直接裁剪），要做滚动布局用手写 flex 更可控。

浏览器实测：视口 569 → shell 569 → content 521(569-48 header) → 内容 750 超出，content 内滚动（scrollTop 0→229），header 固定 top:0，body 不滚动。✓

## DataTable 行数上限 + 表头 sticky

DataTable 增加 3 个 props：
- `maxRows?: number` — 最多显示行数（0 或 undefined = 不限制）
- `maxHeight?: number` — 直接指定最大高度，优先级高于 maxRows
- `rowHeight / headerHeight` — 估算行高（默认 40/40），用于把 maxRows 换算成 maxHeight

实现：外层包 `.data-table-scroll` 滚动容器，computed 计算 maxHeight + overflow-y:auto。

### 踩坑（重点）
**naive-ui n-data-table 内部结构里 `.n-scrollbar-container(overflow: scroll)` 和 `.n-data-table-base-table-body(overflow: hidden)` 都会成为 sticky 元素的"最近滚动祖先"，导致 `position: sticky` 的 thead 跟随滚动而非固定**（overflow: hidden 也算滚动容器）。必须用 :deep 把这两个的 overflow 强制改成 visible，让唯一的滚动祖先是外层 .data-table-scroll，sticky 才能相对外层生效。

WorkbenchView 演示配置 `:max-rows="8"`，配合 50 行数据（用户改的），实测：maxHeight=360、滚动 300 表头不动、滚动条在表格右侧。
